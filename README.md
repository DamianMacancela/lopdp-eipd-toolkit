# LOPDP EIPD Toolkit

Este repositorio contiene un kit de herramientas y plantillas para facilitar la creación de **Evaluaciones de Impacto en Protección de Datos (EIPD)** en el marco de la normativa ecuatoriana (LOPDP) y estándares internacionales como ISO/IEC 29134.

El propósito de este proyecto no es dar asesoramiento legal, sino brindar una estructura organizada y estandarizada en formato Markdown para que ingenieros de seguridad, analistas y gestores de TI puedan documentar riesgos de privacidad sin tener que inventar la rueda cada vez.

## 📄 Contenido del Toolkit

- `plantilla_EIPD.md`: Una plantilla exhaustiva lista para usarse, estructurada para cubrir el ciclo de vida del dato, análisis de necesidades, evaluación de riesgos e implementación de controles.
- **Matrices de Riesgo:** Ejemplos pre-diseñados para categorizar amenazas de privacidad según Probabilidad e Impacto.
- **Flujos de datos:** Sugerencias para documentar mapeo de datos.

## ⚖️ El Cruce entre Seguridad y Privacidad

Como apasionado de la ciberseguridad, aprendí que asegurar una base de datos contra inyecciones SQL es solo la mitad del trabajo. La otra mitad es garantizar que los datos que protegemos estén siendo tratados de manera legal, con el consentimiento adecuado y un riesgo residual documentado.

Este proyecto es el resultado de explorar cómo convergen la gobernanza de TI, el cumplimiento normativo (compliance) y el despliegue técnico.

## Uso

1. Copia el archivo de la plantilla desde `docs/plantilla_EIPD.md`.
2. Renómbralo para tu proyecto específico (ej. `EIPD_NuevoSistemaCRM.md`).
3. Sigue las instrucciones incrustadas (en formato de comentario/cita) para rellenar los datos de tu caso de uso.
4. Expórtalo a PDF (usando herramientas como Pandoc o cualquier editor de Markdown) para presentarlo formalmente si es necesario.

## Renuncia de Responsabilidad

Este repositorio y sus plantillas se ofrecen "tal cual". Están creados a partir de la interpretación técnica de las normativas de privacidad y marcos de riesgos. **No constituyen asesoramiento legal oficial.** Siempre consulta a los asesores jurídicos de tu organización para validar el cumplimiento normativo.
